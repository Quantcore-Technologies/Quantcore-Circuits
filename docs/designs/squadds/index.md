# SQuADDS designs

SQuADDS is a database of superconducting-qubit designs with simulated parameters (MIT licence). Its tutorial 5 builds a complete "fab-ready" four-qubit chip from a database design. The notebook here rebuilds that chip on the Quantcore PDK.

|---|---|---|---|---|
