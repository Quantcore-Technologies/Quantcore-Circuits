# Design specs: index

Each row links a buildable spec. Specs live in
`docs/designs/<group>/<id>.md` (group = legacy | kqc | metal | qpdk | devicelayout | squadds | sqdmetal | community | ibm | google | amplifiers).

**Buildable now?** `yes` = every catalog ref resolves today in `Designer.add` (Quantcore cells + any KQC class by bare
name). `metal` = needs `metal:<Class>` wrappers (planned in `assembly/plan.py`, not resolvable yet). `no` = needs a
MISSING component (listed). Priority: P1 = build first, P2 = next, P3 = reference only.

The notebooks that build these designs were rewritten in a segmented form: see [how a design notebook works](notebook-template.md).

## Conventions used in every spec

- Units µm, degrees; rotation counter-clockwise. Coordinates are in the **Designer frame**: chip box `(0, 0, W, H)`,
  origin at the lower-left corner. Sources centred on (0, 0) (all legacy QWri chips) are shifted by `+W/2, +H/2`;
  the spec says so and also gives the source coordinate where useful.
- Legacy KLayout `Trans(rot, mirror, x, y)` codes: rot 0/1/2/3 = 0/90/180/270°; `mirror=True` mirrors about the x axis
  *before* rotating (y → −y).
- Catalog refs: Quantcore `Xmon`, `BondPad`, `TrilayerJunction`, `TrilayerSquid`; KQC class names (`Swissmon`,
  `Launcher`, `FingerCapacitorSquare`, …); Quantum Metal `metal:<Class>`; or `MISSING: <legacy cell / external
  component>`.
- Routes are `d.route(name, from_port, to, meander=L | type="cpw", nodes=[...], a=, b=)`. A λ/4 readout is a route
  from a qubit claw to `feedline.hanger(s, length, side, ground_gap, direction, end)`; `s` is arclength along the
  feedline's node polyline from its start port; `side` is relative to the feedline's travel direction
  (left = +y when travelling +x). `meander` = total centre-line length of the route including the coupler.
- `ground_gap` (hanger) = metal strip between the two CPW gaps = |Δy| − a_fl/2 − b_fl − a_res/2 − b_res.

## Spec template

```
# <id>: <name>
Source · licence · what it is · chip size/frame · layers · status (buildable now? missing?)
## Components      | instance | catalog ref | key params (units) | at (x, y) | rot | notes |
## Routes          | route | from → to | type, length | waypoints / hanger (s, length, side, ground_gap) | notes |
## Launchers, pads, test structures, markers, labels
## LOM node structure (qubit ↔ resonator ↔ feedline ↔ bus ↔ control lines)
## Targets (if stated)
## Simplifications for a first rebuild
```
