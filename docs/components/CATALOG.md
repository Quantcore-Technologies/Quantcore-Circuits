# Component catalog

Generated by `python scripts/make_catalog.py` on 2026-11-16 from `quantcore_circuits.layouts.catalog.catalog()`. Do not edit by hand.

**143 components** usable as a `design.json` `cell` (57 Quantcore, 45 KQCircuits, 41 Quantum Metal), 109 with a LOM model; plus 25 whole chips (reference cells) and 6 Metal routes (not cells: use a qcc route).

* **ref** goes into `design.json` `cell` / `Designer.add(name, ref, ...)`; `metal:<Class>` takes the Metal options as params.
* **ports**: the ports of a default instance, read from the cell built through the design-plan path (`qcc components <ref>` prints positions, directions and CPW widths). A port marked † has no direction (cannot be snapped to; see the note).
* **LOM**: a lumped model is registered (`quantcore_circuits.lom.fragment.lom_model(ref)`).
* **origin**: the legacy QWri file a Quantcore cell reproduces (golden XOR tests in `tests/test_golden_legacy*.py`; full map in `MIGRATION.md`).
